O que é uma estrutura sequencial em programação?

A estrutura sequencial é a forma mais básica de organização em programação, onde os comandos são executados um após o outro, na ordem exata em que foram escritos, de cima para baixo

O que é uma variável? Dê um exemplo.

é um espaço reservado na memória do computador usado para armazenar dados (como números, textos ou estados) que podem ser alterados durante a execução de um programa

Cite 3 exemplos de ultilizados em programção e explique cada um.

Variáveis: guardam dados Ex: idade = 25 . Funções: reutilizam código, Ex: função que retorna uma saudação, Condicionais: tomam decisões,Ex: if idade >= 18 → maior ou menor de idade

Para que serve uma estrutura condicional?

controlar o fluxo de execução de um programa, permitindo que ele tome decisões e execute blocos de código específicos apenas se uma determinada condição for verdadeira ou falsa

O que é uma estrutura de repetição?

comandos de programação que permitem executar um bloco de código múltiplas vezes até que uma condição específica seja satisfeita ou um número determinado de iterações seja atingido

Dê um exemplo do cotidiano onde ocorre repetição

Escovar os dentes, o movimento de escovar é repetido diversas vezes assim como o ato de respirar.

O que são operadores? Cite dois exemplos.

são símbolos especiais ou palavras-chave que indicam ao compilador ou interpretador para realizar manipulações específicas, como cálculos matemáticos, comparações lógicas ou atribuição de valores, em um ou mais dados. EX: "", <>, !, +, =, -

Para que servem os operadores relacionais ?

Os operadores relacionais servem para comparar dois valores ou expressões em programação, estabelecendo uma relação entre eles

O que significa um valor booleano?

Um valor booleano é um tipo de dado lógico na computação que representa apenas dois estados possíveis: verdadeiro (true/1) ou falso (false/0)

O que é uma expressão lógica ?

é uma combinação de variáveis, constantes e operadores (relacionais ou lógicos) que, ao ser avaliada, resulta estritamente em um valor booleano: Verdadeiro (true/1) ou Falso (false/0)

Para que serve um fluxograma?

mapear visualmente a lógica de um algoritmo, sistema ou processo antes de escrever o código real, utilizando símbolos padronizados (retângulos, losangos, setas).

O que é um pseudocódigo ?

é uma forma genérica e simplificada de escrever algoritmos usando linguagem natural

Qual a diferença entre algoritmo e programa ?

Algoritmo é a lógica passo a passo para resolver um problema (receita), enquanto programa é a implementação desse algoritmo em uma linguagem de computador (o prato pronto)

O que é um erro lógico ?

é uma falha na estrutura de raciocínio do código que faz com que o programa execute sem travar, mas produza resultados incorretos, inesperados ou comportamentos indesejados.

Por que a lógica é tão importante ?

A lógica de programação é a base de todo desenvolvimento de software, permitindo estruturar o pensamento para resolver problemas complexos por meio de instruções sequenciais, claras e eficientes

Por que um algoritimo preicisa ser escrito em ordem ?

porque ele funciona como uma receita passo a passo para o computador, onde a ordem das ações determina o resultado final
